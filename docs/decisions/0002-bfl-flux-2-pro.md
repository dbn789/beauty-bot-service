# D-0002. Провайдер и модель генерации: bfl.ai, FLUX.2 [pro]

**Дата:** 2026-10-10 · **Статус:** принято (Э2) · **Пересмотр:** после приёмки на 10 реальных фото клиентов (ТЗ, раздел 13)

## Решение

| Параметр | Значение |
|---|---|
| Провайдер | **bfl.ai** (официальный API Black Forest Labs) |
| Модель | **`flux-2-pro`** (режим редактирования, `input_image` = фото клиента) |
| Base URL | глобальный `api.bfl.ai` не отвечает из части сетей РФ (DPI/Azure Front Door) → **`https://api.eu.bfl.ai/v1`** (env `BFL_BASE_URL`) |
| Цена | ~$0.045 за вариант → ~$0.135 за генерацию (3 варианта) |
| Альтернатива отклонена | `flux-2-klein-9b` ($0.015): личность держит, но причёска неточная (вместо каре до подбородка — до плеч) и лёгкие артефакты по контуру волос |
| `flux-2-flex` | отклонён: дороже pro для редактирования ($0.06), специализация — типографика |

## Последствия

- Дефолт `BFL_MODEL=flux-2-pro` уже в конфиге; цены в `packages/shared/pricing.js`.
- Бюджет-стоп: $5/день ≈ 37 генераций/день на pro — с запасом для одного салона.
- Ожидаемый UX: полный цикл ~30–45 с (таймаут 120 с с запасом; статусы и chat action уже реализованы).
- Риск: глобальный эндпоинт на Amvera (Москва) может вести себя так же, как локально — на Э3 проверить и при необходимости прописать `BFL_BASE_URL=https://api.eu.bfl.ai/v1` в переменных проекта.
